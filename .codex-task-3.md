## 1. A phone needs a way past the game

The `.game` panel is `height: calc(100svh - 104px)`, so on a 390x844 phone a reader scrolls a full
screen past a pet before reaching a word of documentation. There is a `.skip` link, which helps
keyboard users and nobody else.

Add a visible, touch-sized control that a thumb can actually hit, placed so it is obvious rather than
discoverable. Options, roughly in order of preference:

- a persistent small link pinned to the bottom-right of the `.game` panel, at least 44x44 CSS pixels,
  that jumps to the first documentation section. It must not cover the game's own buttons; check the
  game's layout at 390x844 and place the control where the pet's controls are not.
- or a short line directly under the game panel.

It must be real, not decorative: clicking it moves the document. It must not appear on desktop where the
fold already shows plenty, or if it does appear it must be harmless. It must not obscure the game, and
it must not change the game's own behaviour.

## 2. Make the sound system inspectable instead of asserted

The sound section currently states "12 effects, 8 rooms". That is a claim. This account publishes
numbers you can re-read, so a claim in a place where a measurement belongs is exactly the wrong thing.

Turn those two numbers into figures the build reads, the same way every other figure on the page is
read: extend `build.py` to count the actual files in `audio/sfx/` and `audio/music/` and pass the counts
into the template as placeholders. If a folder is missing or empty the page must say so rather than
showing a number that came from nowhere.

While you are in there, name the eight rooms on the page, and read them from what is actually on disk
rather than typing the list by hand. If a room file is missing, the page should not claim the room
exists.

The QA-mismatch rule from §6 applies to this too: a number that cannot be traced to a source is worse
than no number.

## 3. The four forms should differ visibly, not only in words

Right now the four form cards are visually identical and the reader has to read closely to learn that
steward tidies after itself while drifter asks more often.

Make the difference legible at a glance without changing what each one does — the game's behaviour is
not yours to touch. Each card may carry its verb, its trigger, or a simple mark that distinguishes the
four from each other at a glance. Use the existing palette only. Do not add an icon font, an illustration
set, or any external asset. Do not imply the forms are ranked or that one is better: the page already
says none of them is, and a drifter is not a failure state.
