Twelve effects, one per game event. Each prompt named the event and nothing else, so the set is a map of
the pet's day rather than a generic library. Dry, close, toy-sized — as if the box were the size of a hand.

| file | event | the sound |
|---|---|---|
| `feed` | feeding | soft ceramic bowl tap, tiny wooden spoon |
| `snack` | a sweet | one wrapped crinkle, high and light |
| `play` | playing | wooden ball bounce twice on a table |
| `hit` | the ball game | one high hollow toy pop |
| `clean` | the brush | three soft swishes on cardboard |
| `pet` | being petted | very soft low contented hum |
| `medicine` | the vial | glass uncork, one drop |
| `lights` | the light switch | soft click, filament hum fading |
| `poop` | the mess | small wet plop in an empty tin can |
| `grow` | it grew | gentle rising four-note wooden chime |
| `critical` | a need is critical | soft low descending two-note warning |
| `asleep` | it fell asleep | a tiny soft snore, two breaths |
